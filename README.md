# Akan Name Generator

## Project Description
The Akan Generator is a simple web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender. Akan names are derived from Ghanian culture, where children are named according to the day of the week they were born.

## Setup Instructions

1.Clone the repository to your machine.
2.Open the project folder in VS Code
3.Open index.html with live server
4.Enter your birthdate,select your gender,and click Generete to see your Akan name.

## Behavior Driven Development(BDD)
.Given a user selects a valid birthdate
.When the user selects their gender and clicks Generate
.Then the app calculates the day of the week and displays the correct Akan name
